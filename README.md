# 카드뉴스 작업실

## 채널 선택과 자동 실습

처음 만드는 경우 **새 기획**을 누르고 입력칸을 클릭하거나 Tab 키로 이동하세요. 각 입력칸 아래에 작성 요령과 솔티귤 입력 예시가 표시됩니다. **모든 입력 예시 보기**를 누르면 안내를 한꺼번에 펼칠 수 있습니다.

기획 화면에서 게시 채널을 고르세요. 인스타그램은 4:5(1080 × 1350), 블로그와 유튜브는 16:9(1280 × 720), 카카오톡 홍보와 페이스북은 1:1(1080 × 1080)이 자동으로 선택됩니다. 카드 초안을 만들거나 자동 실습을 시작하면 선택한 비율이 미리보기와 PNG에 적용됩니다. 유튜브용 첫 카드는 썸네일 후보로 활용할 수 있습니다.

**자동 실습 시작**을 누르면 카드 초안과 프롬프트가 만들어지고 이미지 생성 단계가 열립니다. 단계 아래의 버튼으로 **이미지 수정 → 카드 편집 → 검수 → 전체 카드 ZIP 다운로드**를 이어갑니다. ChatGPT에서는 프롬프트를 붙여넣고 이미지를 저장한 뒤 앱의 카드 편집에서 첨부하세요. Canva에서 작업하려면 **Canva에서 이어서 편집하기**의 치수 안내에 따라 디자인을 만들고 Canva에서 PNG를 내려받으세요. 앱의 ZIP에는 앱 미리보기에 표시되는 카드 전체가 담깁니다.

1. `index.html`을 Edge나 Chrome에서 엽니다. 설치나 서버 실행 없이 시작할 수 있습니다.
2. 처음 화면의 솔티귤 5장 또는 동네 책교환 예시를 둘러보세요. **새 기획**을 누르면 자기 주제로 시작할 수 있습니다. 아이디어를 한 장면씩 줄바꿈하거나 `제목 | 핵심 문구 | 이미지에 담을 장면`으로 입력하면 초안이 구체적입니다.
3. **카드 초안 만들기**를 누르고 카드별 생성 프롬프트를 읽어 보세요. 초안은 브라우저가 입력 내용을 조합해 만듭니다. 줄 수가 적으면 보조 장면을 제안하고, 줄 수가 많으면 관련 입력을 한 카드에 묶습니다.
4. **실행 방법 열기 → 복사하고 ChatGPT에서 실행**을 누릅니다. 새 탭에서 붙여넣고 전송하세요. 복사가 막히면 프롬프트 입력란을 직접 선택해 복사하세요. 수정 단계에서는 ChatGPT에 원본 이미지를 첨부하고, 바꿀 한 가지를 적은 뒤 **다시 만들기**를 누릅니다. 수정 프롬프트가 이미 있으면 덮어쓸지 확인합니다.
5. **카드 편집**에서 문구와 장면 설명을 바꾸고 이미지 파일을 추가하세요. 수정한 문구를 프롬프트에 반영하려면 해당 프롬프트를 다시 만드세요. Canva를 사용한다면 같은 크기의 페이지에 이미지를 넣고 제목과 설명을 별도 텍스트로 추가하세요.
6. **검수**에서 장마다 체크합니다. 인스타그램 게시글의 설명도 최종 카드 문구와 맞춰 주세요. **현재 카드 PNG 저장**은 선택한 장 한 장을 내려받습니다. 4:5는 1080 × 1350 px입니다. 첨부 이미지는 그림 영역에 맞춰 가운데를 기준으로 잘립니다.
7. **프로젝트 저장**으로 문구, 프롬프트, 첨부 이미지, 검수 상태를 JSON에 보관합니다. **불러오기**에서 이 파일을 선택하세요. 기획을 수정했다면 카드 초안을 다시 만든 후 저장할 수 있습니다.

솔티귤 사례는 20년간 가꾼 아버지의 유기농 감귤밭에서 시작해 외관 때문에 생과 판매가 어려운 감귤의 가치, 제주 감귤 문화, 감귤과 자연 천일염의 조합 구상, 솔티귤 콘셉트 공개로 이어집니다. 마지막 카드의 ‘AI 제품 구상 예시 / 패키지 미확정’ 표기를 게시 전 확인하세요. 원료와 배합은 개발 단계입니다. 기본 그림은 카드 배치 확인용입니다.

## AI 서버를 연결하려면

- 정적 버전의 `promptFor`는 이미지 요청 문구를 만들고, 카드의 `photo` 필드는 미리보기 및 PNG에 사용됩니다. 호스팅 버전에서 생성·수정 요청을 같은 서비스의 서버 엔드포인트(예: `POST /api/images`)로 보내고, 반환된 결과를 사용자 확인 후 카드 이미지로 적용할 수 있습니다.
- 서버에서만 환경 변수나 비밀 관리 기능으로 공급자 키를 관리하세요. 로그인 확인, 호출 한도, 파일 크기·형식 검증, 시간 제한을 서버에서 처리하세요. 수정에는 사용자에게 전송 대상을 설명하고 고칠 이미지를 함께 보냅니다.
- 버튼을 활성화하기 전에 요청 중 상태, 취소, 응답 오류 및 재시도 흐름을 연결하세요. PNG 저장을 위해 이미지 응답은 같은 사이트에서 전달하거나 브라우저가 읽을 수 있는 이미지 데이터로 받으세요. 기존 ChatGPT 열기 방식도 계속 쓸 수 있습니다.
